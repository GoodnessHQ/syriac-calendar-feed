# Syriac Calendar Feed

Public rolling ICS feeds for the Syriac liturgical calendar.

- Site: https://raw.githubusercontent.com/GoodnessHQ/syriac-calendar-feed/feature/refresh-openspec-and-remove-legacy-source/
- Feeds: `en.ics`, `sv.ics`, `nl.ics`, `syc.ics`, `syc-Latn.ics`
- Feedback: https://raw.githubusercontent.com/GoodnessHQ/syriac-calendar-feed/feature/refresh-openspec-and-remove-legacy-source/feedback.html

Use the site index to subscribe with `webcal://` links or download the feeds directly.
