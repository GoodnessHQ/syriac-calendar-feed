# Syriac Calendar Feed

Public rolling ICS feeds for the Syriac liturgical calendar.

- Site: https://goodnesshq.github.io/syriac-calendar-feed/
- Feeds: `en.ics`, `nl.ics`, `syc.ics`, and `syc-Latn.ics`
- Feedback: https://goodnesshq.github.io/syriac-calendar-feed/feedback.html

Use the site index to subscribe with `webcal://` links or download the feeds directly.
