# Syriac Calendar Feed

Public rolling ICS feeds for the Syriac liturgical calendar.

- Site: https://raw.githubusercontent.com/SyriacOrthodox/syriac-calendar-feed/feature/migrate-public-feed-ownership/
- Feeds: `en.ics`, `sv.ics`, `nl.ics`, `syc.ics`, `syc-Latn.ics`
- Feedback: https://raw.githubusercontent.com/SyriacOrthodox/syriac-calendar-feed/feature/migrate-public-feed-ownership/feedback.html

Use the site index to subscribe with `webcal://` links or download the feeds directly.
